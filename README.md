# Massini

Massini is a collection of open source libraries focused on game development and multimedia applications.

# Disclaimer:

Massini is currently in Alpha state (expect many bugs, ugly apis, etc.), anything can change, be deprecated or deleted at any time. We don't recommend using Massini for commercial/critical projects in its current state.
